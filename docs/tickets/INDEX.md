- [038](open/high/038-judgment-gate.md) — **Judgment gate**: every roster decision today is STRICTLY NUMERIC, and fantasy has judgment numbers don't carry. Owner's two examples split: "too many players from one team" is a CONSTRAINT (count teams; `max_players_per_nfl_team: 3` in config — deterministic, can't hallucinate), while "Yahoo hasn't adjusted for a starter being out" is mostly a DATA gap (#036: injuries + depth charts + projection staleness) with a judgment residue. Core safety property: **the LLM may SUBTRACT, never ADD** — it can veto or annotate but never originate a move or change a number, so its worst case is inaction (the failure mode this system prefers everywhere). Runs on the escalation model, not the 12b, which would add variance not judgment. **One voice**: ledger stays explicit and two-stage for audit, but the DM reads as a single brain — never "the regression model wanted X but I said no" — while still hedging so a read sounds different from a calculation. **The human has the final say** (resolved 2026-08-09): a veto blocks only the unattended path — against an explicitly approved move it warns once, in the same message, and the move proceeds.
