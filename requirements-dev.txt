# so CI cannot run without it.
#
# The repo is PRIVATE, so this needs credentials CI does not have by default:
# the checkout's GITHUB_TOKEN is scoped to this repository alone. CI therefore
# needs a PAT with `repo` scope in a secret, and the workflow rewrites the URL
# to use it (see .github/workflows/ci.yml). Making the package public would
# remove the need for any of that.
#
# Locally it is an editable install instead, so edits to the package are live:
#     python -m pip install -e C:\Users\awarm\sleeperdraft
# pip keeps whichever was installed last, and the editable one wins if present.
#
# NOT vendored back into pc/, deliberately: two copies of a DOM adapter drift
# in exactly the place that costs a draft.
