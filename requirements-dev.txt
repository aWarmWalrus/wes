# Test deps — the minimal set to import the PC modules and run the fast,
# hardware/API-free unit suite. This is what CI installs
# (.github/workflows/ci.yml); for a full PC runtime install use
# pc/requirements.txt.
#
#   python -m pip install -r requirements-dev.txt
#   python -m pytest tests/ --ignore=tests/test_e2e.py
#
# Every pin below has cp311 + cp312 manylinux wheels, so CI does not build from
# source.
#
# NOT included, deliberately, and confirmed unnecessary:
#   discord.py — wes_discord's unit tests pass without it.
# If a new module top-level-imports one of these, add it here AND say why.
#
# playwright USED to be on that list — wes_yahoo gates every use behind
# _have_playwright(). It now arrives anyway, as a dependency of sleeperdraft
# below. Only the Python package: CI never runs `playwright install`, so no
# browser binary is downloaded and nothing here launches one.

# THE SLEEPER DOM LAYER, its own public repo now:
#   https://github.com/aWarmWalrus/sleeperdraft
# `wes_sleeper` top-level-imports it, so CI cannot run without it. Public means
# pip clones it anonymously -- no secret, no URL rewrite, no workflow step.
#
# Locally it is an editable install instead, so edits to the package are live:
#     python -m pip install -e C:\Users\awarm\sleeperdraft
# pip keeps whichever was installed last, and the editable one wins if present.
#
# NOT vendored back into pc/, deliberately: two copies of a DOM adapter drift
# in exactly the place that costs a draft.
sleeperdraft @ git+https://github.com/aWarmWalrus/sleeperdraft@master
